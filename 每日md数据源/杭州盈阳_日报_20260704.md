================================================================================
【总】客户整体消耗下跌明显，ROI小幅下滑
================================================================================

昨日消耗161431.54元，环比下跌35921.06元（18.20%），
ROI为1.5908，环比下滑0.1063（6.26%），
下单次数4076次，环比减少1136次（21.80%）。

消耗下跌幅度较大，但ROI下滑幅度相对较小（-6.26%），说明效果指标相对稳定，
消耗下跌主要来自拿量能力下降而非效果恶化导致的主动控量。

================================================================================
【分】消耗下跌主要归因于以下维度
================================================================================

1. 链路维度（主因）
--------------------------------------------------------------------------------
CID链路消耗下跌29249.70元（29.06%），
该链路为唯一投放链路，消耗占比100%，ROI环比下滑0.0912。

CID链路是消耗下跌的直接载体，客户投放完全集中在此链路，
缺乏其他链路（如小店、直播）的补充，导致整体消耗波动风险高。

2. 版位维度
--------------------------------------------------------------------------------
微信视频号版位消耗下跌22384.46元（47.01%），
为消耗主力版位（占比约56%），ROI环比下滑0.0291。

微信视频号作为主力版位，消耗下跌幅度较大，可能原因：
- 版位竞争加剧，CPM上升导致拿量成本增加
- 流量波动，视频号流量供给减少
- 定向策略调整，人群覆盖范围缩小

3. 人群年龄维度
--------------------------------------------------------------------------------
65+年龄段消耗下跌16893.71元（34.83%），
为消耗主力人群，ROI环比下滑0.1173。

65+年龄段是消耗占比最高的人群，消耗下跌幅度最大，
说明该年龄段人群的拿量能力明显下降，需重点关注：
- 是否定向设置调整导致覆盖范围缩小
- 是否该年龄段竞争加剧导致成本上升
- 是否该年龄段效果恶化导致系统自动降权

4. 人群性别维度
--------------------------------------------------------------------------------
女性人群消耗下跌13939.40元（26.55%），
为消耗主力性别（占比约54%），ROI环比下滑0.1371。

女性人群消耗下跌幅度较大，但ROI环比有所改善（+0.11），
说明女性人群效果相对稳定，消耗下跌可能来自拿量能力下降而非效果恶化。

5. 智投类型维度
--------------------------------------------------------------------------------
非智投广告消耗下跌18097.95元（26.37%），
为消耗主力类型（占比约71%），ROI环比下滑0.0910。

非智投广告消耗下跌幅度较大，说明手动投放策略的拿量能力下降，
需评估是否需要引入智投工具提升拿量效率。

================================================================================
【投放策略分析】
================================================================================

客户投放结构高度集中，缺乏多元化策略：

1. 链路结构：100%集中在CID链路，无小店、直播等其他链路补充
2. 优化目标：100%为下单优化（optimization_goal=204），无其他优化目标
3. 出价策略：100%为稳定拿量（新）（ocpa_bid_strategy=1），无策略切换
4. 是否ROI广告：100%为非ROI广告（is_roi=0），无ROI优化目标设置
5. 智投类型：约71%为非智投广告，约29%为智投广告

投放结构单一化导致：
- 抗风险能力弱，单一链路/版位波动直接影响整体消耗
- 缺乏策略对比，无法通过A/B测试优化投放效果
- 拿量渠道有限，无法通过多策略组合提升整体拿量能力

================================================================================
【风险提示】
================================================================================

1. 投放结构风险（高风险）
   投放结构过于集中，100%依赖CID链路和下单优化目标，
   缺乏多元化策略，抗风险能力弱，单一波动直接影响整体。

2. 人群效果风险（中风险）
   主要人群（65+、女性）效果下滑，ROI环比均有所下降，
   需关注定向调整或人群竞争情况，避免效果持续恶化。

3. 版位竞争风险（中风险）
   微信视频号版位消耗下跌，可能存在竞争加剧或流量波动，
   需观察CPM变化趋势，评估版位策略调整必要性。

4. 拿量能力风险（高风险）
   消耗下跌幅度较大（-18.2%），但ROI下滑幅度较小（-6.26%），
   说明主要问题是拿量能力下降而非效果恶化，
   需评估出价策略、定向设置、版位竞争等拿量影响因素。

================================================================================
【建议应对动作】
================================================================================

针对消耗下跌场景，建议采取以下应对动作：

1. 人群优化（优先级：高）
   - 分析65+和女性人群效果恶化原因，检查定向设置是否调整
   - 评估是否需要缩减低效人群或调整定向范围
   - 考虑引入其他年龄段人群，分散人群风险

2. 版位策略（优先级：中）
   - 观察微信视频号CPM变化，定位竞争来源
   - 评估是否需要调整版位策略，向竞争缓和的版位倾斜
   - 考虑使用起量工具回拉消耗

3. 出价调整（优先级：高）
   - 评估当前稳定拿量策略效果，考虑是否需要切换策略
   - 如效果达标，可尝试切换为优先拿量策略提升拿量能力
   - 如效果未达标，需先优化效果再考虑拿量策略

4. 策略多元化（优先级：中）
   - 考虑引入智投广告，提升投放效率和拿量能力
   - 考虑设置ROI优化目标，优化长期价值而非短期下单
   - 考虑拓展其他链路（如小店、直播），分散投放风险

5. 基建优化（优先级：低）
   - 检查广告数量和素材数量是否充足
   - 评估是否需要新增广告或素材提升拿量能力
   - 关注活跃广告和活跃素材数量变化

================================================================================
诊断结论总结
================================================================================

杭州盈阳客户昨日消耗下跌18.2%，ROI下滑6.26%，下单次数减少21.8%。
